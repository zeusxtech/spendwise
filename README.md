💰 SpendWise

Understand your money. Manage your future.

SpendWise is a free, beginner-friendly, open-source personal finance tracker designed to help people understand their spending habits, manage their income, and keep track of their monthly budgets.

🌐 Live Website: https://zeusxtech.github.io/spendwise/

✨ Features

- Dashboard: View your income, expenses, and available balance.
- Transaction Management: Add and delete income and expense records.
- Expense Categories: Organize spending into categories such as food, shopping, travel, bills, health, and education.
- Monthly Budget: Set a monthly spending limit and monitor your progress.
- CSV Export: Export your transaction records.
- Local Storage: Keep your data in your browser without requiring an account.

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

🚀 Getting Started

You can use SpendWise directly through the live website:

https://zeusxtech.github.io/spendwise/

To run it locally:

1. Clone or download this repository.
2. Open the "index.html" file in your web browser.
3. Start adding your income and expenses.

No installation or additional dependencies are required.

🔒 Privacy

SpendWise currently stores transaction data locally in the user's browser using Local Storage.

There is currently no cloud synchronization or user authentication. Do not use it to store highly sensitive financial information.
